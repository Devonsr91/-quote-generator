
# Quote Generator

A simple Python project that displays a random inspirational quote each time it runs.

## Requirements

- Python 3
- pip

## Setup Instructions

1. Clone or download this project.
2. Open the project folder in your terminal.
3. Create a virtual environment:

   python -m venv .venv

4. Activate the virtual environment:

   Windows:
   .venv\Scripts\activate

5. Install dependencies:

   pip install -r requirements.txt

6. Run the program:

   python main.py

## Features

- Contains 10 inspirational quotes.
- Randomly selects a quote each time it runs.
- Displays the quote and author.

## Dependencies

This project uses Python's built-in random module.
No external packages are required.
